# Last Light《文明余晖》V0.1

单人 Web 互动叙事游戏。2847 年，人类确认恒星将在一百年后发生灾变。你扮演最后一百年的执政官，通过三次重大决策影响文明的生存、秩序与记忆。

本版本包含首页、序章、三轮事件、每轮决策后果、两个测试结局、本地自动保存与重新开始。使用 Next.js App Router、TypeScript、Tailwind CSS 4 和 localStorage；无需数据库、账号、密钥或 AI API。恒星和轨道场景由 CSS 绘制，不加载第三方美术或在线字体。

## 启动

推荐 Node.js **24.19.0**（见 `.nvmrc`）。完整开发工具链支持 Node.js 22.12+（22.x）、24.x 或 26+，其中 Vitest 5 的要求高于 Next.js 本身。依赖版本与 `package-lock.json` 已固定。项目将 npm 缓存放在忽略的 `.npm/` 目录，方便受限云环境使用。

```bash
cd /workspace/last-light # 本地开发时替换为自己的仓库路径
npm ci
npm run dev
```

默认端口为 3000。可用 `npm run dev -- --port 3001` 更换端口。开发配置允许本机 `localhost` 和 `127.0.0.1`；如果使用其他开发访问域名，按 Next.js 文档将具体主机名添加到 `next.config.ts` 的 `allowedDevOrigins`。

生产模式：

```bash
npm run build
npm run start
```

生产构建后首页为静态预渲染页面，游戏交互在浏览器中运行。浏览器需要启用 JavaScript。

## 测试与检查

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

- **Vitest：** 63 项测试，覆盖全部 27 种决策组合、指标变化与上下界、结局门槛、合法状态转换、存档验证及存储失败。
- **Playwright：** 12 项测试，覆盖桌面 Chromium 和手机尺寸下的两条完整结局路线、刷新恢复、重开取消与确认、损坏存档、禁用存储、键盘选择，以及 320px 窄屏各阶段布局。手机测试是浏览器设备模拟，不代表真机或 Safari 验证。

浏览器测试运行在**生产构建**上，先运行 `npm run build`。Playwright 会启动生产服务并在测试结束后关闭它。确保 3000 端口没有被其他应用占用；本地已有该项目生产服务时可以复用。

```bash
# 首次在普通本地环境安装 Playwright 浏览器
npx playwright install chromium
npm run test:e2e
```

当前云环境已有系统 Chromium，无需额外下载：

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

`npm run test:watch` 可在开发时持续运行规则测试。浏览器测试失败时，诊断 trace 存放在忽略的 `test-results/` 中。

## 文件结构

```text
src/
  app/
    layout.tsx              页面元信息、语言与根布局
    page.tsx                游戏入口
    globals.css             Tailwind 主题、终端样式与响应式布局
  components/
    game.tsx                游戏界面、决策选择、存档提示与重开确认
    icon.tsx                本地 SVG 图标
    stellar-scene.tsx        CSS 恒星、轨道与结局场景
  game/
    types.ts                剧情、指标、状态与结局类型
    story.ts                序章、事件、选项、后果和结局文案
    engine.ts               独立纯函数规则引擎
    storage.ts              版本化本地存档适配
    engine.test.ts           规则、路径与状态验证测试
    storage.test.ts          存档、重开与异常测试
tests/e2e/game.spec.ts       真实浏览器完整流程测试
```

剧情数据不依赖 React。规则引擎不访问浏览器或存储，UI 通过它进行状态转换，存档适配单独负责读写。调整剧情文案在 `story.ts` 中完成；改变规则需同时调整规则测试。

## 确定性规则

初始指标为**资源 60、科技 40、稳定 65、传承 45**，范围均为 0–100。每个选项显示四项固定变化，没有随机数。玩家选中方案后还需确认，确认后展示后果，已归档决策不能撤回。

三轮事件依次发生在 2848、2862、2889 年，最终记录发生在 2947 年。事件之间为叙事时间跳跃，没有额外模拟或隐藏回合。

| 回合 | 决策 | 资源 | 科技 | 稳定 | 传承 |
| --- | --- | ---: | ---: | ---: | ---: |
| 真相的重量 | 公开完整真相 | -5 | +10 | -15 | +10 |
| 真相的重量 | 分阶段公布 | -5 | +5 | +5 | -5 |
| 真相的重量 | 暂时保密 | 0 | +5 | +10 | -20 |
| 稀缺的未来 | 优先方舟工程 | -20 | +25 | -10 | -5 |
| 稀缺的未来 | 优先文明档案 | -10 | +5 | +5 | +25 |
| 稀缺的未来 | 共同推进 | -15 | +15 | 0 | +10 |
| 第一道裂痕 | 公民议会 | -5 | +5 | +15 | +10 |
| 第一道裂痕 | 集中权力 | 0 | +10 | -20 | -10 |
| 第一道裂痕 | 自治契约 | +15 | +5 | -5 | +5 |

结局规则在界面中公开：

- **方舟计划：** 最终资源 ≥ 50、科技 ≥ 65、稳定 ≥ 45，三项条件必须同时满足。
- **文明之书：** 未能同时达到三项远航条件。
- **传承质量：** 传承 ≥ 70 为「丰厚的记忆」，45–69 为「留存的片段」，低于 45 为「稀薄的回声」。两个结局都会显示具体保存程度与决策记录。

便于验收的两条路线：

| 路线 | 三轮选择 | 最终指标（资源 / 科技 / 稳定 / 传承） |
| --- | --- | --- |
| 方舟计划 | 分阶段公布 → 优先方舟 → 自治契约 | 50 / 75 / 55 / 40 |
| 文明之书 | 公开真相 → 优先档案 → 公民议会 | 40 / 60 / 70 / 90 |

## 本地存档

使用 `last-light:v0.1` 键，保存版本号、当前阶段与有序决策 ID。每次推进阶段或确认决策时自动保存，包括后果页与结局。刷新后在首页点击「继续执政」或「查看文明档案」恢复。

恢复时验证阶段和决策顺序，重新计算指标，不信任存档中额外的指标数值。损坏或不兼容存档会显示提示，不会在读取时覆盖；开启新游戏后才写入新档案。存储被禁用或额度不足时仍可完成游戏，但会提示刷新将丢失未保存进度。重新开始需确认，仅覆盖本游戏的键。

进度仅属于当前浏览器的当前站点，清除站点数据会删除存档。不同设备、浏览器、端口或域名之间不共享进度。

## V0.1 边界

这是一个完整可通关的最小版本，含三个回合、每轮三个选项与两个测试结局。不含额外回合、复杂分支、云存档、账号、AI 内容或音频。后续优先通过试玩校准数值、措辞与选择后果，再评估扩展剧情或美术。
